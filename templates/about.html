About APKManifest

APKManifest is a static analysis tool for Android applications developed as part of the SMD Mobile Security course project at POLITEHNICA București. It analyzes the AndroidManifest.xml file inside an APK and detects common security misconfigurations.

How it works

The tool opens the APK file using androguard and extracts the AndroidManifest.xml. It then runs five security checks on the manifest and maps each finding to its corresponding OWASP MASVS control, assigns a severity level, and provides a recommended fix. A risk score from 0 to 100 is calculated based on the findings.

What it checks

  • Dangerous permissions — permissions classified as dangerous by the Android official documentation, requiring explicit user approval
  • Debuggable flag — android:debuggable="true" allows ADB debugger attachment in production builds (MASVS-RESILIENCE-2)
  • Backup flag — android:allowBackup="true" allows ADB extraction of private app data (MASVS-STORAGE-1)
  • Cleartext traffic — android:usesCleartextTraffic="true" permits unencrypted HTTP connections (MASVS-NETWORK-1)
  • Exported components — activities, services, and receivers exposed to other apps without permission protection (MASVS-PLATFORM-1)

Limitations

APKManifest analyzes the AndroidManifest.xml only. It does not analyze application source code, compiled bytecode, or runtime behavior. Vulnerabilities inside the application logic — such as hardcoded secrets, SQL injection, or insecure cryptography — are outside the scope of this tool. All findings should be verified manually before action is taken.

Tech stack

Python · Flask · androguard · ReportLab · HTML/CSS
